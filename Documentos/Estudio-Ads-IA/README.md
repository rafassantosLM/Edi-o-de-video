# Estúdio Ads IA

| Pasta | O que vai aqui |
|---|---|
| `brutos/` | Gravações originais, sem edição (nunca são alteradas — servem de "negativo") |
| `referencias/` | Anúncios de inspiração, roteiros, prints, trilhas de exemplo |
| `geracoes/` | Tudo que for produzido: cortes, versões com legenda, formatos 9:16 / 1:1 / 16:9 |

Ferramentas do ambiente: FFmpeg 6.1.1 · Node.js 22 · Python 3.11+ · uv
